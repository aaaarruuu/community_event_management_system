# Community Event Management System

A Java-based Community Event Management System designed to simplify the process of organizing, managing, and maintaining community events through a centralized application.

## Overview

The Community Event Management System provides a structured way to manage community events and their related information. Instead of maintaining event details manually, the system provides an organized application where event-related operations can be handled efficiently.

The project is developed using Java and follows a modular application structure, making it suitable for further extension and integration with additional event-management features.

## Objectives

* Simplify community event management
* Maintain event information in an organized manner
* Reduce manual effort involved in managing events
* Provide a structured application for event-related operations
* Create a foundation that can be extended with additional features

## Features

## Getting Started

### Prerequisites

Make sure the following software is installed:

* Java JDK
* IntelliJ IDEA
* Git

### Clone the Repository

```bash
git clone https://github.com/aaaarruuu/community_event_management_system.git
```

### Open the Project

1. Open IntelliJ IDEA.
2. Select **Open**.
3. Choose the cloned `community_event_management_system` directory.
4. Allow IntelliJ IDEA to configure the project.
5. Make sure the project is using a compatible Java JDK.
6. Build and run the application from the available main class.
